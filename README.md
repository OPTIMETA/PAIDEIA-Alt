# paideia-alt — **Exam Radar**

> Optimeta의 Alt 플러그인 **인지·전환 쐐기**. 강의 녹음 트랜스크립트에서 *"무엇을 공부하고 무엇을 버릴지"* 를 시험일까지 운영하는, 강의가 쌓일수록 자라나는 **2D 결정 맵**.

- **이건 제품이 아니다.** Optimeta MVP인 **PAIDEIA Study OS**(v1 Claude Code 플러그인 / v3 데스크톱)의 깔때기 최상단 쐐기다 — 제품을 대체하지 않는다.
- **본질**: 콘텐츠(퀴즈) 엔진이 아니라 **결정(triage) 엔진**. *"퀴즈를 더 만들지 마라. 무엇을 버릴지부터 정하라."*
